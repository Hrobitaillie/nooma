# Nooma — Mots-clés YouTube pour la pipeline Blender → app

> Recherches à faire en **anglais** en priorité (10x plus de contenu, souvent de meilleure qualité).
> Conseil de méthode : commencer par la section 4 (sprite sheets) — c'est le maillon qui valide toute la pipeline (Test A de la Phase 1 du plan projet). Le style clay est le plus agréable à explorer mais le moins risqué.

## 1. Le style pâte à modeler dans Blender

- `blender clay style tutorial` / `blender claymation style`
- `blender clay material subsurface scattering`
- `blender stop motion look` / `blender stop motion animation style`
- `blender plasticine character`
- `blender cute stylized character tutorial` (beaucoup de résultats proches du rendu kawaii/clay)
- `blender fingerprint texture clay` (effet empreintes de doigts)

**Chaînes à repérer** : Polyfjord, **Southern Shotty** (spécialiste du rendu clay/felt/stop-motion — quasi exactement la DA Nooma), CG Geek, Blender Guru.

## 2. La carte-monde (décor de jeu vu de haut)

- `blender stylized game map environment`
- `blender isometric diorama tutorial` (le format diorama mignon est très proche d'une carte de monde)
- `blender low poly world map`
- `blender orthographic camera game asset`
- `game world map design tutorial` (côté game design : composition du chemin et des nœuds)
- `mario world map design analysis` (pour la structure, pas la technique)

## 3. Le rendu en couches (pour le parallax)

- `blender view layers tutorial` (nom officiel de la fonctionnalité)
- `blender render passes explained`
- `blender render transparent background` (pour les couches et objets isolés)
- `blender collections render layers separate`
- `2d parallax background game tutorial` (côté intégration : comprendre ce qu'attendent les couches)

## 4. Les sprite sheets depuis Blender ⭐ (à faire en premier)

Le maillon le moins documenté sous ce nom exact — varier les formulations :

- `blender render sprite sheet` / `blender animation to sprite sheet`
- `blender render animation as png sequence` (l'étape de base : séquence d'images)
- `blender 3d model to 2d sprite` — technique dite "pre-rendered sprites", très documentée
- `pre rendered sprites blender godot` (beaucoup de tutos visent Godot mais la partie Blender est identique)
- `donkey kong country pre rendered graphics how` (comprendre la technique historique)
- Outil à connaître : `texture packer sprite sheet tutorial` (assembler la séquence PNG en sprite sheet)

## 5. L'intégration côté app (Flutter + Flame)

- `flutter flame tutorial 2024` / `flame engine flutter game`
- `flame sprite animation tutorial` / `flame spritesheet animation`
- `flame parallax component` (Flame a un composant parallax natif — exactement le besoin de la carte)
- `flutter interactiveviewer pan zoom` (carte pannable/zoomable en Flutter pur)
- `flutter flame level map`

## 6. Bonus utiles pour plus tard

- `webp vs png game assets` (poids des assets)
- `blender turntable render product` (pour les images-mots : template studio réutilisable)
- Rig de Nooma : `rig simple character blender shape keys`, `blender shape keys facial expressions`, `blender simple armature rig`
